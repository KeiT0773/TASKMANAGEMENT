## 2. 画面一覧

| ID | 画面名 | 役割 |
| --- | --- | --- |
| SC-01 | ボード画面 | メイン画面。3つのリストとカードを一覧表示し、カードの追加・移動・並べ替え、全リストの優先度順並べ替えを行う |
| SC-02 | カード詳細 | 1枚のカードの説明文・期限・優先度を確認・編集する。ボード画面から呼び出す |

---

## 3. 画面構成の要件

- ボード画面では「未着手」「作業中」「完了」の3つのリストを横に並べて表示し、スクロールせずに同時に見渡せること。
- 各リストの中では、カードを表示順に従って縦に並べること。
- カードの表面には、詳細を開かなくてもタイトル・優先度・期限が読み取れること。説明文はカード詳細でのみ表示する。
- 各リストに、そのリストへカードを追加する操作を配置すること。追加時にはタイトルと優先度を入力できること。
- すべてのリストのカードを優先度順に並べ直す操作を、リストの枠の外（ヘッダーとリストの間のツールバー）に 1 つ配置すること。全リスト共通の操作であることが分かるようにする。
- カード詳細は、ボード画面の表示を保ったまま開閉できること（別ページへは遷移しない）。

---

## 4. 画面遷移

ボード画面（SC-01）とカード詳細（SC-02）の間の往復のみとする。他の画面は存在しない。

## 5. 画面イメージ

各画面の構成を以下に示す。要素の配置と表示項目を伝えるための概略であり、色・寸法・装飾は基本設計で定める。

### 5.1 SC-01 ボード画面

```
┌──────────────────────────────────────────────────────────────┐
│ タスク管理ボード                                             │
├──────────────────────────────────────────────────────────────┤
│ [優先度順に並べ替え]                                         │
├────────────────────┬────────────────────┬────────────────────┤
│ 未着手             │ 作業中             │ 完了               │
├────────────────────┼────────────────────┼────────────────────┤
│ ┌────────────────┐ │ ┌────────────────┐ │ ┌────────────────┐ │
│ │ [高] 資料作成  │ │ │ [中] 実装      │ │ │ [低] 掃除      │ │
│ │ 期限 09/15     │ │ │ 期限 09/20     │ │ │                │ │
│ └────────────────┘ │ └────────────────┘ │ └────────────────┘ │
│ ┌────────────────┐ │                    │ ┌────────────────┐ │
│ │ [中] 買い物    │ │                    │ │ [中] 返信      │ │
│ │ 期限 09/10 (!) │ │                    │ │ 期限 09/11     │ │
│ └────────────────┘ │                    │ └────────────────┘ │
│ ┌────────────────┐ │                    │                    │
│ │ [低] 読書      │ │                    │                    │
│ │                │ │                    │                    │
│ └────────────────┘ │                    │                    │
│                    │                    │                    │
│ ＋ カードを追加    │ ＋ カードを追加    │ ＋ カードを追加    │
└────────────────────┴────────────────────┴────────────────────┘
```

- `[高] [中] [低]` は優先度を表す。実際の画面では色付きの表示とする（FR-08）。
- `(!)` は期限を過ぎているカードを表す。実際の画面では他と区別できる表示とする（FR-07）。
- 期限が未設定のカードは、期限の行を空欄とする。
- カードをクリックするとカード詳細（SC-02）が開く。
- カードはドラッグで列の間および列の中を移動できる（FR-04, FR-05）。
- 各列の下部の「＋ カードを追加」からカードを登録する（FR-01）。押すと、その場にタイトルの入力欄と優先度の選択が表示される（下記「カード追加の入力欄」参照）。
- カードの登録後、およびカード詳細で優先度を変更した後は、そのリスト内が優先度順（高→中→低）に並べ直される（機能要件書 3.1）。ドラッグでの並べ替えは自由に行える。
- ヘッダーとリストの間のツールバーにある「優先度順に並べ替え」を押すと、3 つの列すべてがそれぞれの中で優先度順（高→中→低）に並び直る（FR-10）。同じ優先度のカードどうしの順序は変わらない。確認は求めない。ボタンは全リスト共通のため、各列の枠の中には置かない。

#### カード追加の入力欄

「＋ カードを追加」を押したときの、列の下部の表示。

```
│ ┌────────────────┐ │
│ │ タイトルを入力 │ │
│ └────────────────┘ │
│ ( ) 高 (●) 中 ( ) 低 │
│ [追加] [キャンセル] │
└────────────────────┘
```

- タイトルは必須。空のまま「追加」を押しても登録されない（FR-01）。
- 優先度の初期値は「中」。登録後にカード詳細（SC-02）からも変更できる。
- 「キャンセル」で入力欄を閉じ、「＋ カードを追加」の表示に戻る。

### 5.2 SC-02 カード詳細

ボード画面の手前に重ねて表示し、閉じるとボード画面に戻る。

```
┌────────────────────────────────────────────┐
│ カード詳細                        [閉じる] │
├────────────────────────────────────────────┤
│ タイトル                                   │
│ ┌────────────────────────────────────────┐ │
│ │ 資料作成                               │ │
│ └────────────────────────────────────────┘ │
│ 説明文                                     │
│ ┌────────────────────────────────────────┐ │
│ │ 来週の定例会議で使う資料。             │ │
│ │ 前回の議事録を参照すること。           │ │
│ └────────────────────────────────────────┘ │
│ 期限               優先度                  │
│ ┌────────────┐     [ ] 高 [x] 中 [ ] 低    │
│ │ 2026/09/15 │                             │
│ └────────────┘                             │
│                                            │
│                           [ カードを削除 ] │
└────────────────────────────────────────────┘
```

- タイトル（FR-02）、説明文（FR-06）、期限（FR-07）、優先度（FR-08）をこの画面で編集する。
- 削除ボタン（FR-03）は、誤操作を防ぐためボード画面のカード表面には置かず、この画面の下部に配置する。
- 「閉じる」でボード画面に戻る。編集内容は閉じる前に保存されている（FR-09）。
